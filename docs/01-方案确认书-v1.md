## 1. 学习体系设计（产品的灵魂）

四条线共用一套"知识点树"，但**训练方式不同**：

### 线① 电工基础（PLC 的地基，也是另两张证的地基）
直流电路（欧姆定律·串并联·基尔霍夫）→ 电磁基础 → 交流电（相量·功率·功率因数）→ 三相电路 → 电工仪表使用

### 线② 低压电工特种作业操作证（考证 = 刷题为主）
安全法律法规与用电常识 / 电工基础 / 仪表与工具 / 电工材料与导线连接 / 低压电器与电动机 / 电气控制线路 / 安全操作与触电急救 / 照明与配电 / 防雷接地

> **考证的关键认知**：这类证的理论考试通常从**官方题库**抽题。所以这条线最高效的不是"AI 出新题"，而是**把你手上的官方题库导进来刷**：顺序练 → 随机练 → 模拟考 → 错题重刷。AI 的价值在于**给错题讲原理**。

### 线③ 电工中级职业技能等级证
理论知识（电路分析 / 模拟数字电路基础 / 电机与拖动 / 电气控制 / PLC 基础 / 电气测量）+ 实操技能
> 实操部分 App 只能辅助（图解步骤、工艺要求、视频索引），不能替代动手。

### 线④ PLC（你的最终目标）
硬件结构与工作原理 / 输入输出接线 / 梯形图与基本指令 / 定时器与计数器 / 顺序控制 / 典型控制电路（电机启停、正反转、星三角降压启动）/ 编程思路与调试

> ⚠️ 以上是**框架草案**。等你告诉我考试地区/教材后，我可以去核对官方考纲再精修。

## 2. 产品形态：一个 App，两种模式

| 模式 | 用在 | 干什么 |
|---|---|---|
| **A. 刷题模式（考证）** | 低压电工证、中级等级证理论 | 导入题库 → 顺序/随机/模拟考 → 错题本 → 掌握度 |
| **B. AI 出题模式（学习）** | 电工基础、PLC | 喂材料（链接/文档/截图）→ 出大纲 → 出题组卷 → 做题 → AI 阅卷 |

两种模式**共用同一个内核**：知识点标签 + 错题本 + 掌握度模型 + 遗忘曲线排程 + 学习者画像。所以你在刷题模式错的东西，AI 出题模式会自动针对性补。

## 3. 自进化引擎（你要的四项，全是核心）

```
做题结果
   ↓
① 知识点掌握度模型   ← 每题挂知识点标签，带遗忘衰减
   ↓
② 遗忘曲线复习排程   ← SM-2/FSRS 类算法，自动安排"今天该复习什么"
   ↓
③ 自适应出题/组卷    ← 下一张卷子自动提高薄弱知识点占比 + 难度爬坡
   ↓
④ 学习者画像迭代     ← 沉淀"你总错在哪、错因是什么、哪种讲法你听得懂"，
                        每次出题/讲解自动注入这份画像
   ↓
⑤ 薄弱点补强微讲义   ← 针对弱点自动生成"3 分钟讲清 + 3 道即时巩固题"
   ↓
   （回到做题，形成闭环）
```

## 4. 输入层设计（全免费渠道）

| 输入 | 手段 | 自动化程度 |
|---|---|---|
| B站视频链接 | 优先抓官方 CC 字幕（免费接口） | 有字幕→全自动；无字幕→提示你贴文本 |
| MOOC / 国家智慧教育平台 网页 | 抓网页正文/课程目录 → Markdown | 较自动 |
| 抖音 | 无公开字幕接口 | 主要靠你**粘贴文案或截图** |
| 讲义文档 | 上传 PDF / PPTX / DOCX / TXT | 全自动（最准） |
| 电路图 / 公式截图 | 拍照/相册 → **GLM-4V** 识图 | 半自动（识别后可人工修） |
| 纯文本 | 直接粘贴 | 万能兜底 |

**诚实边界**：我**不承诺"丢个链接就全自动"**——大模型打不开视频网页，看不到画面和声音。有字幕/讲义就自动，没有就请你贴一下。

## 5. 技术方案（已定）

| 层 | 选择 |
|---|---|
| 前端 | React + TypeScript + Vite（PWA 可装到桌面） |
| 本地数据 | IndexedDB（Dexie）——题库/错题/掌握度全离线，隐私好、零服务器成本 |
| 安卓壳 | **Capacitor**（本机已有 Node，无需 Rust/NDK；原生 HTTP 可绕 CORS） |
| 打包 | 本地 Gradle（后期）+ GitHub Actions 云打包 + Release |
| 大模型 | OAI 兼容协议；默认 DeepSeek（文本）+ GLM-4V（视觉），可切豆包/通义/Ollama |
| 判分 | 客观题**本地判**（免费·离线·100% 准）；主观/计算题 AI 按评分点给分 |

## 9. 风险与诚实边界

| 风险 | 说明 |
|---|---|
| 大模型看不了视频 | 必须靠字幕/讲义/截图，已设计兜底路径 |
| 无字幕课程自动化程度低 | 抖音尤其如此，只能粘贴/截图 |
| AI 改计算题可能算错 | 采用"分步评分点 + 你可申诉重判"降低影响 |
| 识图对复杂电路图仍有误差 | 识别结果允许你手动修正后再入库 |
| 手机端 API Key 安全 | Key 只存本机 IndexedDB，不进代码、不推 GitHub |
| 网络 | 调大模型需联网；GitHub 操作我会自动带代理参数 |
