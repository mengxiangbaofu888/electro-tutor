# 上手指南（给使用者）

> 这份是**给你看的**，不需要任何技术背景。
> 开发 / 打包 / 架构那些在 `02-架构说明.md`、`03-开发与部署步骤.md` 里。

---

## 一、你需要准备什么

**只有一样：一个大模型的 API Key。**

| 服务商 | 推荐程度 | 说明 |
|---|---|---|
| **DeepSeek** | ⭐ 首选 | 最便宜、中文最强，出题和批改主力用它 |
| **智谱 GLM** | ⭐ 建议再加一个 | 识图（拍课件、电路图）要用视觉模型，它的 `glm-4v-flash` 有免费档（以服务商当期定价为准） |
| 通义千问 / 豆包 | 可以 | 也都能用，看你手上有什么 Key |

一个 Key 大概几块钱就能用很久——**一套 20 题的卷子大约几分钱**（按 DeepSeek 的公开定价估算）。
客观题（选择/判断/填空）判分**完全不花钱**，在本机算。

> 不想花钱也行：本地电脑跑 Ollama 也能接，见最后一节。

### 装到手机上（安卓）

**先试网页版**：手机浏览器打开项目站点就能用，不用装、不用等。
另外还有离线单文件版和 APK 版，都在 `03-开发与部署步骤.md` 里。

APK 版的好处：能离线打开、网络请求走原生通道（不受浏览器跨域限制）。
安装包在 `android/app/build/outputs/apk/debug/app-debug.apk`（跑 `npm run apk` 生成）。

把它传到手机上（微信文件传输助手 / QQ / 数据线 / 网盘都行），用「**文件管理**」找到、
点开安装。系统一定会拦一下「未知来源」，各家位置不太一样：

| 你的手机 | 怎么放行安装 |
|---|---|
| MIUI 12 / 12.5 | 设置 → 应用设置 → 应用管理 → 右上角「⋮」→ 特殊权限 → **安装未知应用** → 找到你点开 apk 的那个应用（文件管理 / 浏览器）→ 允许 |
| HyperOS 3 | 安装时弹的窗口里点「**仍要安装**」；若没这个按钮：设置 → 应用设置 → 权限管理 → 右上角「⋮」→ 特殊权限 → 安装未知应用 |
| OriginOS 6（vivo） | 安装时点「**继续安装**」并允许；被拦时：设置 → 更多设置 → 权限管理 → **安装未知应用** → 允许「文件管理」 |
| 其他安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

> 各版本菜单位置会差一两个字，找不到就在**设置顶部的搜索框里搜「未知应用」**，一步直达。

四个坑，先说了省得你来回试：

1. **别在微信里直接点 apk**——微信会拦掉安装（它不是文件管理器）。用「用其他应用打开」，
   或者直接进文件管理 → 下载目录 → 点它。
2. 装的时候提示「未经安全检测 / 应用来源不明」是**正常的**，选继续安装。
   这是自己构建的调试签名包，对所有非应用商店来源，系统都会这么提示。
3. 装好后第一次用要先配 Key：「我的」→「大模型配置」（下一步就说这个）。
4. 以后有新版本，**直接覆盖安装就行**，大纲、题库、错题本都不会丢——数据存在手机本地，
   只有你主动卸载才会清掉。

## 二、三步开始（大约 5 分钟）

### 第 1 步：配好模型
打开 App → 底部「**我的**」→「**大模型配置**」：

1. 「① 先选服务商」选一个（推荐 DeepSeek）；
2. 点「**🔑 填 API Key（从这里开始）**」按钮，弹出的表单里：
   - **① API Key**：把服务商的 Key 粘进去（只存在手机本地，不会上传）；
   - **② 接口地址**：选了预设已经自动填好，不用动；
   - **③ 模型**：**你自己选**。填完 Key 后点开这个框（或点「从服务商获取模型列表（联网）」），
     程序会去服务商那里把它**当前可用**的模型列表拉回来，点一下标签就选中。
     也可以直接点「常用」里的标签，或自己手填模型 ID。
3. 点「**测试连接**」看到回复就说明通了 → 点「**保存**」。

> 💡 建议配两个：一个文本模型（DeepSeek）负责出题批改，
> 一个识图模型（GLM 的 `glm-4v-flash`，免费）负责看课件截图。
>
> 💡 模型是按**你填的 Key 实时查**的，所以服务商上新模型、下架旧模型，
> 你这里点一次「获取模型列表」就是最新的——不用等 App 更新。

### 第 2 步：装上起步大纲
底部「**大纲**」→ 找到「📦 内置起步大纲」→ 点「**一键装上全部四条线**」。

这一步**不花一分钱、不调用模型**。四条线各自的知识点数量：

| 学习线 | 知识点数 | 覆盖内容 |
|---|---|---|
| 电工基础 | 32 | 电路基本概念 → 欧姆定律 → 基尔霍夫 → 电磁 → 交流电 → 三相 → 仪表 |
| PLC | 29 | 硬件结构 → IO 接线 → 梯形图指令 → 定时器计数器 → 顺序控制 → 典型电路 → 调试 |
| 低压电工证 | 49 | 法规 → 安全用电 → 触电急救 → 防火防爆 → 电工基础 → 仪表工具 → 材料导线 → 低压电器电机 → 控制线路 → 照明配电 → 接地防雷 → 作业规范 |
| 电工中级等级证 | 32 | 电路分析定理 → 交流分析 → 模电数电 → 电机拖动 → 控制与 PLC → 测量 → 工艺 |

（这四个数字由测试自动核对，改了内置大纲而忘记改这里会立刻失败。）

> 为什么要有这一步：不装的话你打开 App 是空的，
> 得先自己找材料才能开始。装上之后立刻就能出题。

### 第 3 步：出题、做题、看报告
底部「**练习**」→ 选一份大纲 → 点「**生成并开始答题**」→ 做完点「**交卷批改**」。

然后你会看到：
- 总分 + 老师总评
- **错在哪、为什么错、怎么补**
- 这次暴露的薄弱点
- 逐题复盘（含解析）

## 三、每天怎么用（这才是重点）

学电工不是"做一次题"就完了。这个 App 的设计是让你**每天回来十几分钟**：

```
① 看首页的「今日该复习」  ← 系统按遗忘曲线算好的，照着做就行
        ↓
② 点「练一下」直接开始     ← 题库里没题会自动帮你出，不用先去别处
        ↓
③ 做完看报告，重点看「错因分析」
        ↓
④ 错题进错题本，连续答对两次才移出
        ↓
⑤ 明天回来，① 里的内容会跟着变
```

**「最该补的薄弱点」**那一栏是最该看的：它按你的掌握度排序，
越薄弱排越前面。想快速见效就盯着它练。

### 遇到不会的知识点怎么办？
去「**大纲**」→ 点开某份大纲 → 知识点树里每个点右边有个「**讲**」按钮。

点它，老师会当场给你讲一遍：
**一句话说清 → 为什么是这样（配生活类比）→ 怎么记怎么算 → 最容易错的地方**，
讲完还自动给你 3 道巩固题。

> 这个按钮**不需要你先做错题**，随时可以点。预算够的话，
> 建议对着「电工基础」那条线的知识点挨个点一遍，相当于老师一对一讲了一遍。

## 四、怎么把你手上的视频/网课变成题目

去「**材料**」页，五种方式，按你的情况选：

| 你的情况 | 用哪种 | 省事程度 |
|---|---|---|
| 课程有**配套讲义/PPT/PDF** | 「上传文档」 | ⭐⭐⭐ 最准，直接传 |
| 你**自己记了笔记** | 「粘贴文本」 | ⭐⭐⭐ 很稳 |
| B站视频**有 CC 字幕** | 「B站视频」 | ⭐⭐ 能自动抓 |
| 课件是**图片/你想拍照** | 「拍照识图」 | ⭐⭐ 能识别，复杂电路图要核对 |
| 是**网页教程** | 「网页链接」 | ⭐⭐ 能抓正文 |
| 老师讲的**没字幕也没讲义** | 「粘贴文本」自己打要点，或「拍照识图」拍课件 | ⭐ 只能这样 |

⚠️ **一句实话**：大模型**看不了视频**，它打不开视频网页、看不到画面、听不到声音。
App 能自动抓的是视频**自带的字幕**。没有字幕时，上面这几条兜底路才是现实选择。

> 页面里还有个「题库导入」：以后你要是找到低压电工证的**官方题库（Excel 也行）**，
> 可以直接导进来刷，不用手抄。

## 五、怎么省钱

| 做法 | 效果 |
|---|---|
| 客观题交给本机判分 | **完全免费**（选择/判断/填空都是本机算的） |
| 出题时把「简答/计算」数量调低 | 这两种题要调用 AI 批改，最费钱 |
| 识图用 GLM 的 `glm-4v-flash` | **免费档** |
| 用 DeepSeek 而不是国外模型 | 便宜很多，还不用代理 |
| 出过的题会被存进题库 | 以后练同一批知识点**不会再花钱**（本地抽题） |
| 多练「错题本」和「今日复习」 | 都是从已有题库抽题，**不花 token** |

## 六、常见问题

<details>
<summary><b>完全不想花钱，能用吗？</b></summary>

能，但要分清楚：

- **能用的**：内置的四套起步大纲、翻看知识点、导入自己的材料（不调用模型的部分）、
  从已有题库抽题练习、本机判分、错题本、掌握度地图。
- **用不了的**：AI 出题、AI 批改主观题、AI 识图、AI 讲解——这些都要模型。

零成本方案：在电脑上装 [Ollama](https://ollama.com/download) 跑个开源模型，
然后在「模型配置」里填电脑的局域网地址（如 `http://192.168.1.10:11434/v1`）。
两个前提：① 电脑上的 Ollama 要监听局域网（设 `OLLAMA_HOST=0.0.0.0` 后重启）；
② 手机和电脑在同一个 WiFi 下。
</details>

<details>
<summary><b>它说抓不到视频内容</b></summary>

大模型看不了视频，App 只能抓视频**自带的 CC 字幕**。没有字幕就抓不到。

替代办法（按推荐顺序）：找课程配套讲义上传 → 自己把要点粘贴进来 → 拍课件截图识图。
</details>

<details>
<summary><b>识图（拍课件）准不准？</b></summary>

常见文字、公式、简单电路图识别得不错；**复杂电路图和手写体会有误差**。

所以：识别完请到材料列表里点「预览内容」核对一遍，不对就删掉重来。
图片在发送前会自动压缩（长边缩到 1280），省流量也省钱。
</details>

<details>
<summary><b>AI 批改的分数我觉得不对</b></summary>

主观题（简答/计算）的批改确实可能有偏差，所以做了两件事：

1. 批改时会**按评分点分步给分**——思路对只算错数不会全扣，报告里能看到每一步的得分；
2. 报告页可以「**重新生成报告**」再跑一次。

如果它把标准答案判错了，那多半是出题时答案本身就不严谨。
建议到「练习」页换一批题，或者把那个知识点用「讲」按钮讲一遍对一下。
</details>

<details>
<summary><b>换手机数据会不会丢？</b></summary>

**会。数据只存在这台手机上，没有云端。**

换设备前：到「我的 → 数据备份」→ 点「**导出备份**」。

⚠️ App 版会弹出系统面板让你选存到哪（网盘 / 微信 / 本机文件）——
**请确认面板里确实保存成功了**。如果你点了取消，App 会提示你"备份没有生成"。

新手机上：同一个位置点「**导入备份**」，选那个 JSON 文件即可。
（备份文件**不含 API Key**，可以放心存网盘。）
</details>

<details>
<summary><b>提示"网络请求被拦截"</b></summary>

网页版是浏览器直接请求大模型接口的。实测 DeepSeek、智谱 GLM、通义千问、豆包
**都允许浏览器直连**，正常不会遇到。

万一遇到：① 在「模型配置」里填**代理前缀**；② 或改用 App 版（原生请求不受跨域限制）。
</details>

<details>
<summary><b>听说 App 版和网页版不一样？</b></summary>

功能一样，两个区别：

- **App 版**不受浏览器跨域限制，导出文件走系统的保存/分享面板；
- **网页版**在浏览器里跑，导出文件是浏览器下载。

数据**不互通**（网页版和 App 版各自存自己的），建议固定用一个。
</details>

## 七、想让题目更准怎么办

AI 出题的质量，**七分靠材料、三分靠模型**。所以：

1. **优先传讲义**：有 PDF/PPT 就传，比凭模型自己的知识出题准得多；
2. **在大纲里删掉不需要的知识点**：范围越聚焦，题越贴；
3. **练习页可以填「补充要求」**，例如「多出一些需要判断串并联的题」；
4. **做完发现某道题的答案不对**，就把那个知识点的题重新生成一批
   （同一知识点多练几次，好题会留下来）。

另外「学习者画像」（在「我的」页）会越用越准：它记录你**反复犯的错**，
每次出题、讲解、批改都会带上这份画像。用得越多，它越知道该往哪儿考你。
嫌它更新慢，可以手动点「用最近的答题刷新」。
