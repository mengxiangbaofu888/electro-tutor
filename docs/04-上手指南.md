# 上手指南（给使用者）

> 这份是**给你看的**，不需要任何技术背景。
> 开发 / 打包 / 架构那些在 `02-架构说明.md`、`03-开发与部署步骤.md` 里。

## 一、你需要准备什么

**只有一样：一个大模型的 API Key。**

| 服务商 | 推荐程度 | 说明 |
|---|---|---|
| **DeepSeek** | ⭐ 首选 | 最便宜、中文最强，出题和批改主力用它 |
| **智谱 GLM** | ⭐ 建议再加一个 | 识图（拍课件、电路图）要用视觉模型，它的 `glm-4v-flash` 有免费档（以服务商当期定价为准） |
| 通义千问 / 豆包 | 可以 | 也都能用，看你手上有什么 Key |

一个 Key 大概几块钱就能用很久——**一套 20 题的卷子大约几分钱**（按 DeepSeek 的公开定价估算）。
客观题（选择/判断/填空）判分**完全不花钱**，在本机算。

> 不想花钱也行：本地电脑跑 Ollama 也能接，见最后一节。

### 装到手机上（安卓）

**先试网页版**：手机浏览器打开项目站点就能用，不用装、不用等。
另外还有离线单文件版和 APK 版，都在 `03-开发与部署步骤.md` 里。

APK 版的好处：能离线打开、网络请求走原生通道（不受浏览器跨域限制）。
安装包在 `android/app/build/outputs/apk/debug/app-debug.apk`（跑 `npm run apk` 生成）。

把它传到手机上（微信文件传输助手 / QQ / 数据线 / 网盘都行），用「**文件管理**」找到、
点开安装。系统一定会拦一下「未知来源」，各家位置不太一样：

| 你的手机 | 怎么放行安装 |
|---|---|
| MIUI 12 / 12.5 | 设置 → 应用设置 → 应用管理 → 右上角「⋮」→ 特殊权限 → **安装未知应用** → 找到你点开 apk 的那个应用（文件管理 / 浏览器）→ 允许 |
| HyperOS 3 | 安装时弹的窗口里点「**仍要安装**」；若没这个按钮：设置 → 应用设置 → 权限管理 → 右上角「⋮」→ 特殊权限 → 安装未知应用 |
| OriginOS 6（vivo） | 安装时点「**继续安装**」并允许；被拦时：设置 → 更多设置 → 权限管理 → **安装未知应用** → 允许「文件管理」 |
| 其他安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

> 各版本菜单位置会差一两个字，找不到就在**设置顶部的搜索框里搜「未知应用」**，一步直达。

四个坑，先说了省得你来回试：

1. **别在微信里直接点 apk**——微信会拦掉安装（它不是文件管理器）。用「用其他应用打开」，
   或者直接进文件管理 → 下载目录 → 点它。
2. 装的时候提示「未经安全检测 / 应用来源不明」是**正常的**，选继续安装。
   这是自己构建的调试签名包，对所有非应用商店来源，系统都会这么提示。
3. 装好后第一次用要先配 Key：「我的」→「大模型配置」（下一步就说这个）。
4. 以后有新版本，**直接覆盖安装就行**，大纲、题库、错题本都不会丢——数据存在手机本地，
   只有你主动卸载才会清掉。

## 二、三步开始（大约 5 分钟）

### 第 1 步：配好模型
打开 App → 底部「**我的**」→「**大模型配置**」：

1. 「① 先选服务商」选一个（推荐 DeepSeek）；
2. 点「**🔑 填 API Key（从这里开始）**」按钮，弹出的表单里：
   - **① API Key**：把服务商的 Key 粘进去（只存在手机本地，不会上传）；
   - **② 接口地址**：选了预设已经自动填好，不用动；
   - **③ 模型**：**你自己选**。填完 Key 后点开这个框（或点「从服务商获取模型列表（联网）」），
     程序会去服务商那里把它**当前可用**的模型列表拉回来，点一下标签就选中。
     也可以直接点「常用」里的标签，或自己手填模型 ID。
3. 点「**测试连接**」看到回复就说明通了 → 点「**保存**」。

> 💡 建议配两个：一个文本模型（DeepSeek）负责出题批改，
> 一个识图模型（GLM 的 `glm-4v-flash`，免费）负责看课件截图。
>
> 💡 模型是按**你填的 Key 实时查**的，所以服务商上新模型、下架旧模型，
> 你这里点一次「获取模型列表」就是最新的——**App 里不再预置任何"推荐模型"**，
> 免得你照着过时的名字填、结果调不通。
>
> ⚠️ **识图要用真的有视觉能力的模型**。比如 DeepSeek **没有视觉模型**，
> 拿它当识图模型必然失败（界面会直接提醒你）。识图推荐智谱 GLM 的
> `glm-4v-flash`（有免费档）。
>
> ✅ **配好识图模型后，一定要点一下「测试连接」**：
> 对识图配置，它**会真的发一张小图**过去、让模型说出看到了什么
> （不是只发一句话）。所以：
> · 显示"识图正常：模型说它看到…" → 这个模型**真的能看图**，可以放心用；
> · 显示"模型回话了，但**它好像没看到图**" → 这个模型**不吃图片输入**，换一个；
> · 直接报错 → 同上，换一个。
>
> 这一步能省掉你后面"照片传上去半天没反应/识别不出来"的排查。
> 另外书皮识图会先把照片压到长边 1024（只要看清书名就够），比原来更快。

> ⏱ **如果卡住不出结果**：App 有"空闲超时"——**45 秒没收到任何数据**就会停下并告诉你
> 是哪个模型、打到哪家、下一步怎么做（一般就是模型名不对或服务商在排队）。
> 识图慢一些，给了 90 秒。**只要模型在持续吐字就不会被打断**。

> 🧠 **关于"思考模式"（这一条很关键）**：
> DeepSeek 的 `deepseek-flash`（V4.1-Flash）**默认开着思考模式**——它会先把额度花在
> 思维链上，最后才写答案。出题、生成大纲、判分这些要 JSON 的任务，
> 思考模式只会**更慢更贵，还可能把额度用光导致"空回复"**。
> 所以 App 对这类任务**自动关掉思考模式**（DeepSeek / 通义 / 智谱都认，
> 走中转地址也认；不认识的厂商不会乱发参数，免得被拒）。
>
> 看到"**模型返回了空内容**"或「测试连接」显示"**(模型返回为空)**"时：
> 那**不是**配置正常，而是模型一个字都没给。App 现在会把这种情况**当失败报出来**，
> 并告诉你去点「测试连接」确认。以前这里会骗你说"连接成功"，是我修掉的坑。

### 第 2 步：装上起步大纲
底部「**大纲**」→ 找到「📦 内置起步大纲」→ 点「**一键装上全部四条线**」。

这一步**不花一分钱、不调用模型**。四条线各自的知识点数量：

| 学习线 | 知识点数 | 覆盖内容 |
|---|---|---|
| 电工基础 | 32 | 电路基本概念 → 欧姆定律 → 基尔霍夫 → 电磁 → 交流电 → 三相 → 仪表 |
| PLC | 29 | 硬件结构 → IO 接线 → 梯形图指令 → 定时器计数器 → 顺序控制 → 典型电路 → 调试 |
| 低压电工证 | 49 | 法规 → 安全用电 → 触电急救 → 防火防爆 → 电工基础 → 仪表工具 → 材料导线 → 低压电器电机 → 控制线路 → 照明配电 → 接地防雷 → 作业规范 |
| 电工中级等级证 | 32 | 电路分析定理 → 交流分析 → 模电数电 → 电机拖动 → 控制与 PLC → 测量 → 工艺 |

（这四个数字由测试自动核对，改了内置大纲而忘记改这里会立刻失败。）

> 为什么要有这一步：不装的话你打开 App 是空的，
> 得先自己找材料才能开始。装上之后立刻就能出题。

### 第 3 步：出题、做题、看报告

底部「**练习**」→ 选一份大纲 → 点「**生成并开始答题**」→ 做完点「**交卷批改**」。

> ⏱ **题是一批一批出的**（每批 5 道）。出题时界面上会显示
> 「已出 N / 共 M 道（第 i / k 批）」，**出一道就能先看到一道**，
> 不用等 20 道一起吐完。
> 万一某一批失败了，**前面已经出的题不会丢**，还会告诉你哪一批没成。
> 素材要得多（比如一次 20 道）时，这样比"一口气要 20 道"快得多、
> 也不容易被截断。

然后你会看到：
- 总分 + 老师总评
- **错在哪、为什么错、怎么补**
- 这次暴露的薄弱点
- 逐题复盘（含解析）

## 三、每天怎么用（这才是重点）

学电工不是"做一次题"就完了。这个 App 的设计是让你**每天回来十几分钟**：

```
① 看首页的「今日该复习」  ← 系统按遗忘曲线算好的，照着做就行
        ↓
② 点「练一下」直接开始     ← 题库里没题会自动帮你出，不用先去别处
        ↓
③ 做完看报告，重点看「错因分析」
        ↓
④ 错题进错题本，连续答对两次才移出
        ↓
⑤ 明天回来，① 里的内容会跟着变
```

**「最该补的薄弱点」**那一栏是最该看的：它按你的掌握度排序，
越薄弱排越前面。想快速见效就盯着它练。

### 遇到不会的知识点怎么办？
去「**大纲**」→ 点开某份大纲 → 知识点树里每个点右边有个「**讲**」按钮。

点它，老师会当场给你讲一遍：
**一句话说清 → 为什么是这样（配生活类比）→ 怎么记怎么算 → 最容易错的地方**，
讲完还自动给你 3 道巩固题。

> 这个按钮**不需要你先做错题**，随时可以点。预算够的话，
> 建议对着「电工基础」那条线的知识点挨个点一遍，相当于老师一对一讲了一遍。

## 四、怎么把你手上的视频/网课变成题目

去「**材料**」页，五种方式，按你的情况选：

| 你的情况 | 用哪种 | 省事程度 |
|---|---|---|
| 课程有**配套讲义/PPT/PDF** | 「上传文档」 | ⭐⭐⭐ 最准，直接传 |
| 你**自己记了笔记** | 「粘贴文本」 | ⭐⭐⭐ 很稳 |
| B站视频**有 CC 字幕** | 「B站视频」 | ⭐⭐ 能自动抓 |
| 课件是**图片/你想拍照** | 「拍照识图」 | ⭐⭐ 能识别，复杂电路图要核对 |
| 是**网页教程** | 「网页链接」 | ⭐⭐ 能抓正文 |
| 老师讲的**没字幕也没讲义** | 「粘贴文本」自己打要点，或「拍照识图」拍课件 | ⭐ 只能这样 |

⚠️ **一句实话**：大模型**看不了视频**，它打不开视频网页、看不到画面、听不到声音。
App 能自动抓的是视频**自带的字幕**。没有字幕时，上面这几条兜底路才是现实选择。

> 页面里还有个「题库导入」：以后你要是找到低压电工证的**官方题库（Excel 也行）**，
> 可以直接导进来刷，不用手抄。

### 有纸书怎么办？——「加一本教材」（拍照 + 扫码）

「材料」页顶部有「📚 **加一本教材**」入口，专门对付纸质教材。三步：

| 步骤 | 你做什么 | App 做什么 |
|---|---|---|
| ① | 拍一张**书皮**（或版权页） | 用你配的识图模型认出书名 / 出版社 / 主编 / 版次，自动填进表格 |
| ② | 扫/拍书背的**条形码** | 用解码库解出 **ISBN** 并校验；还能一键到公开书目库补全书名出版社 |
| ③ | 把书上**每节的微课二维码**拍进来（可一次选多张） | 逐张真解码，把链接攒成这本书的微课清单，重复的自动去掉 |

保存后就变成一条材料，可以拿去生成大纲、出题。书的微课链接也都留着。

**关键一步：让 App 自己去把微课内容找出来。**
扫到微课链接之后，微课清单下面有个按钮
「**让 App 去抓这 N 个微课的内容**」。点它，App 会**自己逐个打开这些链接、
把正文抠出来存成材料**——你不用一页页点开看，之后直接去「大纲」或「练习」用就行。

- 抓过的链接不会重复抓（再点会告诉你"之前都抓过了"）；
- 抓不到正文的（**多半是视频页、或需要登录**）会明确告诉你原因，并提示下一步：
  直接点开看，或者把视频里的板书/画面拍下来用「拍照识图」。

> 🔁 **漏了微课可以回头补**：加完教材之后，去「材料」页找到那本书，
> 点「**补充微课 / 编辑**」就能接着扫——已存的书目和微课清单都会带出来，
> 保存是**更新那一本**（不会又新建一条，也不会把创建时间改成今天）。
> 一次可以选很多张（最多 100 张），不用担心漏拍几张要重来。

> ⚠️ **两个诚实的说明**：
> 1. **只扫书皮那一个二维码，凑不齐整本书的微课**——那个码通常只指向出版社的资源首页。
>    所以是"一节一码"：你把每节的码拍进来，App 批量解好，省掉手抄链接的功夫。
> 2. 识图认字**一定会认错**（尤其繁体版次、特殊字形），所以每一项都能直接改——
>    别把它当权威，当成"帮你打好草"就行。

> 💡 扫码是**真解码**（ZXing，完全离线、不联网、不花 API 费用）。
> 不是让 AI 看二维码猜内容——猜出来的网址一个字符错就全废，所以这里必须真解。

> 📌 **实测记录（《零基础学电工》978-7-111-58954-9，机械工业出版社）**：
> 拿这本书的真照片跑过一遍，结论是——
> · 书背**条码**：解出 `9787111589549`，校验通过 ✅（压缩到 1280 也照样能解）
> · 封底那**三个二维码**：解出来是出版社的**微信公众号 / 营销号**（`weixin.qq.com/r/...`），
>   **不是微课资源目录** —— 所以"扫封面一个码拿全本微课"这本书做不到
> · 版权页也写明：微课二维码**印在书中每个知识点旁边**（"在书中重要的知识点或操作技能环节附印有二维码"）
>   → 印证了正确用法就是"一节一码，拍进来批量解"
>
> 另外：**拍整张封底时二维码往往太小**（第一次实测就全失败了），所以 App 会自动把大图
> **切块 + 放大**再解一遍；但你自己拍的时候**靠近一点、让码占满画面**，成功率最高。

> ⏱ **实测耗时**（同一张手机照片，1080×1920）：
> · 拍**近**的条码/二维码 → **0.1 秒**出结果
> · 拍**整张封底**、码只占很小一块 → 要 **7 秒**才能找到（App 会在这期间显示
>   "整张没找到，正在切块放大细找…"，不是卡死）
>
> 所以结论很直白：**一个码拍一张，靠近拍**，又快又准。

> 🔍 **顺便查过的一条路（机工社教材专用）**：版权页上的「教育服务网 cmpedu.com」
> 确实是个**公开、免登录**的资源库（32,000+ 条课件/微课/习题答案，可按书名搜）。
> 但**你这本《零基础学电工》在上面搜不到资源**（按书名和按书号都试过）——
> 它的微课是绑在书内二维码上的。所以对这本书，"扫书里的码"仍然是最实际的路子。

## 四之二、在慕课（icourse163）上学的课：粘一个链接就抓整门课

「材料」页有「🎓 **慕课整门导入**」入口。用法就一步：

**在课程页面复制地址**（要带 `?tid=` 的那一串），粘进 App，点「抓取这门课」。

App 会自己去抓：

| 抓到什么 | 说明 |
|---|---|
| **课时目录** | 这门课有哪些讲、哪些节（实测一门电工课抓到 61 个课时） |
| **课程自测题（含答案）** | 单选/多选/判断/填空都有，含标准答案（实测 1570 道） |

抓完不会直接灌进你的题库，而是**列出来让你一条条挑**：
可以按题型筛、按题干里的字搜、逐题勾选，也可以"全选当前筛选结果"。
挑好点「导入选中的 N 道题」，题目就进题库了——知识点按**课时名**自动建好，
之后去「练习」页就能拿它们出卷。

> ⚠️ **两件必须说清楚的事**：
> 1. **视频抓不到。** 慕课的视频要登录才能看，本功能**不绕过登录**。
>    视频课时会列在课时清单里，想看就点开官方页面看。
> 2. **只有 APK 版能用这个功能。** 慕课服务器不允许浏览器跨域取数据
>    （实测它的跨域响应头是空的），所以网页版会被浏览器拦掉——
>    App 里会直接提示你"请用 APK 版"，而不是报一个看不懂的跨域错误。
>    APK 版走系统原生请求，不受这个限制。

> 💡 慕课的接口是**公开**的，但随时可能变。抓不到时 App 会明确报错
> （带上服务端给的原因），不会静默给你一个空课程。

## 四之三、大纲是怎么来的（什么时候要花钱调模型，什么时候不用）

这条规则是**通用的**，跟具体哪本书、哪门课无关——**看材料里有没有现成的标题清单**：

| 你加的东西 | 材料里自带标题吗 | 建大纲怎么走 |
|---|---|---|
| **慕课链接** | ✅ 有：课时目录（如 61 个课时名） | **本地直接拼**：秒出、不花钱、不联网 |
| **教材（书）** | ✅ 有：你扫到的微课标题（如"11.1 触电急救"） | **本地直接拼**：同上 |
| **PDF / 你的笔记 / 拍照识图** | ❌ 没有：是一整篇文字 | **必须调模型**：让它读一遍再归纳 |
| **网页链接** | 通常没有 | **必须调模型** |

**为什么有标题就不用模型**：标题本身就是知识点的骨架。
让模型去"归纳"一份已经排好的课时目录，只会更慢、更贵，
还可能把你书上的名字改错（比如把"触电急救"写成"触电救护"）。

**为什么不去自己编章节名**：我们只知道标题长什么样，不知道它写的是"第几讲"还是"第几章"，
编一个很可能是错的。所以 App 只按标题**原样铺开**、顺序和来源一致——
这比编一个看起来漂亮但错的结构强。

**在哪里点**：
- 慕课：抓到课程后，课时清单下面有「**用课时列表直接建大纲（不调模型）**」
- 教材 / 任何材料：到「**材料**」页，凡是自带标题的材料都会显示
  「**直接建大纲（N 个标题）**」；没有标题的材料不会显示这个按钮（那些得用 AI）

> 加了一本新书、一门新课？只要它的标题进了 App（扫码 / 抓课程），
> 这条规则就照样生效——**不需要改程序，也不需要我给你单独做**。

## 五、怎么省钱

| 做法 | 效果 |
|---|---|
| 客观题交给本机判分 | **完全免费**（选择/判断/填空都是本机算的） |
| 出题时把「简答/计算」数量调低 | 这两种题要调用 AI 批改，最费钱 |
| 识图用 GLM 的 `glm-4v-flash` | **免费档** |
| 用 DeepSeek 而不是国外模型 | 便宜很多，还不用代理 |
| 出过的题会被存进题库 | 以后练同一批知识点**不会再花钱**（本地抽题） |
| 多练「错题本」和「今日复习」 | 都是从已有题库抽题，**不花 token** |

## 六、常见问题

<details>
<summary><b>完全不想花钱，能用吗？</b></summary>

能，但要分清楚：

- **能用的**：内置的四套起步大纲、翻看知识点、导入自己的材料（不调用模型的部分）、
  从已有题库抽题练习、本机判分、错题本、掌握度地图。
- **用不了的**：AI 出题、AI 批改主观题、AI 识图、AI 讲解——这些都要模型。

零成本方案：在电脑上装 [Ollama](https://ollama.com/download) 跑个开源模型，
然后在「模型配置」里填电脑的局域网地址（如 `http://192.168.1.10:11434/v1`）。
两个前提：① 电脑上的 Ollama 要监听局域网（设 `OLLAMA_HOST=0.0.0.0` 后重启）；
② 手机和电脑在同一个 WiFi 下。
</details>

<details>
<summary><b>它说抓不到视频内容</b></summary>

大模型看不了视频，App 只能抓视频**自带的 CC 字幕**。没有字幕就抓不到。

替代办法（按推荐顺序）：找课程配套讲义上传 → 自己把要点粘贴进来 → 拍课件截图识图。
</details>

<details>
<summary><b>识图（拍课件）准不准？</b></summary>

常见文字、公式、简单电路图识别得不错；**复杂电路图和手写体会有误差**。

所以：识别完请到材料列表里点「预览内容」核对一遍，不对就删掉重来。
图片在发送前会自动压缩（长边缩到 1280），省流量也省钱。
</details>

<details>
<summary><b>AI 批改的分数我觉得不对</b></summary>

主观题（简答/计算）的批改确实可能有偏差，所以做了两件事：

1. 批改时会**按评分点分步给分**——思路对只算错数不会全扣，报告里能看到每一步的得分；
2. 报告页可以「**重新生成报告**」再跑一次。

如果它把标准答案判错了，那多半是出题时答案本身就不严谨。
建议到「练习」页换一批题，或者把那个知识点用「讲」按钮讲一遍对一下。
</details>

<details>
<summary><b>换手机数据会不会丢？</b></summary>

**会。数据只存在这台手机上，没有云端。**

换设备前：到「我的 → 数据备份」→ 点「**导出备份**」。

⚠️ App 版会弹出系统面板让你选存到哪（网盘 / 微信 / 本机文件）——
**请确认面板里确实保存成功了**。如果你点了取消，App 会提示你"备份没有生成"。

新手机上：同一个位置点「**导入备份**」，选那个 JSON 文件即可。
（备份文件**不含 API Key**，可以放心存网盘。）
</details>

<details>
<summary><b>提示"网络请求被拦截"</b></summary>

网页版是浏览器直接请求大模型接口的。实测 DeepSeek、智谱 GLM、通义千问、豆包
**都允许浏览器直连**，正常不会遇到。

万一遇到：① 在「模型配置」里填**代理前缀**；② 或改用 App 版（原生请求不受跨域限制）。
</details>

<details>
<summary><b>听说 App 版和网页版不一样？</b></summary>

功能一样，两个区别：

- **App 版**不受浏览器跨域限制，导出文件走系统的保存/分享面板；
- **网页版**在浏览器里跑，导出文件是浏览器下载。

数据**不互通**（网页版和 App 版各自存自己的），建议固定用一个。
</details>

## 七、想让题目更准怎么办

AI 出题的质量，**七分靠材料、三分靠模型**。所以：

1. **优先传讲义**：有 PDF/PPT 就传，比凭模型自己的知识出题准得多；
2. **在大纲里删掉不需要的知识点**：范围越聚焦，题越贴；
3. **练习页可以填「补充要求」**，例如「多出一些需要判断串并联的题」；
4. **做完发现某道题的答案不对**，就把那个知识点的题重新生成一批
   （同一知识点多练几次，好题会留下来）。

另外「学习者画像」（在「我的」页）会越用越准：它记录你**反复犯的错**，
每次出题、讲解、批改都会带上这份画像。用得越多，它越知道该往哪儿考你。
嫌它更新慢，可以手动点「用最近的答题刷新」。
